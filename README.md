# 隧道 LED 灯条动画广告仿真

地铁隧道墙上的竖直 LED 灯条阵列,利用视觉暂留在乘客视网膜上拼出连贯动画。
本系统仿真整个过程,帮助广告公司在施工前验证:画面会不会撕裂、会不会闪、车速变化时会不会乱。

## 运行

```bash
npm install
npm run dev      # 开发预览
npm test         # 验收指标测试
npm run build    # 类型检查 + 打包
```

## 四大模块

| 模块 | 内容 |
|---|---|
| ① 灯条布置 | 间距、数量、每条像素数、像素间距、刷新率、占空比(3 套预设) |
| ② 列车运行 | 速度曲线(匀速/正弦变速/加减速 4 套预设)、测速延迟与噪声、时序模式 |
| ③ 乘客视角 | 眼睛位置/高度、眼到窗距离、窗到墙距离、车窗尺寸(坐/站/车门旁 4 套预设) |
| ④ 点亮时序 | 按测得车速在线生成每根灯条的点亮时刻与列号,时序图可视化,可导出 CSV |

## 物理模型

- **列车系**:画面锚定在列车参考系,第 `c` 列应出现在列车系位置 `imgU0 + c·colWidth`。
- **点亮时序**:灯条 `n` 在墙面 `x_n`,系统根据**测得**位置 `p̃(t)` 反解,
  当 `x_n - p̃(t) = imgU0 + c·colWidth` 时点亮第 `c` 列。
- **视网膜痕迹**:痕迹锚定在点亮瞬间的**真实**列车系位置 `u = x_n - p(t)`。
  测速有误差时两者对不上 → 画面被拉宽 / 压窄 / 倾斜。
- **视觉暂留**:每条痕迹按 `exp(-Δt/τ)` 衰减,τ 可调(默认 60ms),加性叠加成最终画面。
- **视角**:眼睛透过车窗看墙面,按相似三角形投影;站着/坐着/不同座位看到的范围不同。

## 渲染

WebGL2 实例化渲染:每条暂留痕迹画一个竖条实例(动画列纹理 × 高斯横向剖面 × 余晖权重),
加性混合到浮点帧缓冲,再做曝光与伽马校正。乘客视角画布固定 1920×1080,右上角 HUD 显示实测 FPS。

## 验收指标

1. **车速 60–80 km/h 变化时,按测速自适应后画面横向拉伸 ≤ 2%**
   单根灯条在余晖窗口内扫出一段画面,段内"列号→列车系位置"的斜率 = `(真实速度/测得速度)×列宽`。
   `npm test` 用正弦变速曲线(60–80 km/h)+ 测速延迟/噪声仿真全程,对每根灯条的痕迹分段做
   最小二乘拟合,加权平均斜率相对理想列宽的偏差即拉伸率;段间截距离散度即撕裂度。
   另有两个对照测试:固定假设速度与实际不符时拉伸 > 8%,验证模型确实能反映失配。
2. **乘客视角 1080p ≥ 60 帧**:实例化渲染每帧仅数千个实例,HUD 实时显示 FPS。

## 动画素材

内置 4 套程序化动画(彩条测试 / 弹跳小球 / 滚动文字 / 波浪等离子),
支持上传图片(单图或横向雪碧图)和视频(mp4/webm),上传后立即可见效果。
